# Homebrew Tap for Antigravity eXtension (`agx`)

Official Homebrew tap for installing [**Antigravity eXtension (`agx`)**](https://github.com/imsaba16/agx) on macOS (Apple Silicon & Intel) and Linux.

---

## Installation

Add the tap:
```bash
brew tap imsaba16/agx
```

Install `agx`:
```bash
brew install agx
```

Or install directly in a single command:
```bash
brew install imsaba16/agx/agx
```

---

## Verification

```bash
agx --version
# agx 1.0.0-rc.1
```

---

## Upgrading

To update to the latest version:
```bash
brew update
brew upgrade agx
```
